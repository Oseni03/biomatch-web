# 70: Actionable Donor Dashboard

**What to build:** Re-form the donor dashboard around a single clear next action based on the donor's current state, while retaining the information needed to understand eligibility, availability, matched requests, notifications, history, and rewards.

**Blocked by:** 68: Donor Profile Completion; 69: Server-Side Geolocation Matching

**Status:** ready-for-agent

- [ ] The primary action directs the donor to profile completion, availability, matched requests, an active alert, or relevant cooldown/history state.
- [ ] Only requests matched to the donor are shown as actionable.
- [ ] The dashboard includes verification, eligibility/cooldown, availability, notification, donation-history, and static-rewards states.
- [ ] Loading, query failure, and empty states preserve a usable dashboard shell with focused retry actions.
